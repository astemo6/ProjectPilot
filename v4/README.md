# 项目开发甘特图 v4

由 v3.7（归档：分支 archive-v3.7 / 标签 v3.7-20261011，仓库根目录仍为 v3.7）复制而来。

## 与 v3.7 的区别

- v4.10（2026-10-12）：全功能点击巡检（Ribbon 全部按钮，无脚本错误）；修复「客户里程碑」「周期性任务」「文本样式」「颜色」等对话框按 Esc 无法关闭的问题，现在任何对话框都可用 Esc 关闭最上层。

- v4.9（2026-10-11）：对标 GanttProject：文件 → 导入「GanttProject (.gan)」（任务层级、里程碑、工期、完成%、依赖类型与延隔、资源与负荷、备注、Web 链接、优先级）、「CSV 任务」（自动识别 GanttProject CSV 与本工具导出的 CSV：大纲数字/分组、前置任务、资源[%]、备注、链接，日期支持 2024-03-04、3/4/24、4.3.2024）；导出「GanttProject (.gan)」，可在 GanttProject 中直接打开；MS Project XML 导入新增超链接。

- v4.8（2026-10-11）：任务 → 属性组「📝 备注」（多行备注，Ctrl+Enter 确定）和「🔗 超链接」（显示文字 + 地址，可删除）；右键菜单也有；任务名称右侧显示指示器：📝 备注、🔗 超链接（点击打开）、📅 非「越早越好」的限制、⇩ 期限、⊘ 已停用，悬停看详情；可撤销。

- v4.7（2026-10-11）：任务右键菜单（表格行或甘特条形上右键）：顶部浮动迷你工具栏（字体/字号/B/I/S/颜色/降级/升级/链接），菜单含剪切/复制/粘贴、插入/删除任务、编辑名称、任务信息、文本样式、升级/降级、链接/取消链接、手动/自动计划、停用、按日程标记、添加到日程表、向下填充、滚动到任务、完成% 0~100；编辑框内仍保留浏览器自带菜单。

- v4.6（2026-10-11）：视图 → 数据「突出显示」（标黄符合条件的任务，不隐藏其它任务；含自定义筛选条件）；大纲快捷键 Alt+Shift+- 折叠 / Alt+Shift++ 展开 / Alt+Shift+* 全部展开；F3 清除筛选；Ctrl+Shift+F5 滚动到任务；F1 / 文件 → 帮助「快捷键」列表。
- v4.5（2026-10-11）：快速访问工具栏（页签行右侧）：右键功能区任意按钮「添加到快速访问工具栏」，右键 QAT 按钮删除/上移/下移，▾ 勾选常用命令或重置；Alt+1~9 按顺序调用（命令在其它页签时自动切换过去）。

- v4.4（2026-10-11）：按 MS Project 布局：字体组留在「任务」页签；「格式」页签新增「文本样式」（格式组）和「颜色」（条形图样式组），不必再进「显示 ▾」菜单。

- v4.3（2026-10-11）：工具栏改为 MS Project 式功能区（Ribbon）：文件 / 任务 / 资源 / 报表 / 项目 / 视图 / 格式 七个页签，每页按组排列并带组名；撤销/重做放在页签行右侧（快速访问）；双击页签或 ⌃ 折叠功能区，折叠后点页签临时展开；Alt+F/H/R/E/P/W/O 切换页签；记住上次页签。

- v4.2（2026-10-11）：显示 ▾ → 大纲数字（名称前 1 / 1.1 / 1.2.3）、项目摘要任务（第 0 行汇总整个项目）；筛选 ▾ → 自定义筛选…（最多 4 个条件，且/或；域：名称/资源/工期/开始/完成/完成%/前置/备注/类型/模式/总可宽延；条件：等于/不等于/包含/不包含/大于/小于/≥/≤）。

- v4.1（2026-10-11）：文本样式增加删除线（工具栏 S / Ctrl+5，类别默认样式也可设，PDF/JPG 跟随）；字体扩充到 50+ 种（中文/西文分组，只列本机已安装的），可「＋ 添加本机字体…」（Chrome/Edge 可读取系统字体列表）；切换语言后保存偏好并重新载入，所有菜单/按钮/提示都换成新语言；补齐写死的中文提示；显示菜单「滚动到任务」按钮不再竖排；页头显示版本号。

- 2026-10-11：对标第三轮：显示 ▾ → 分组依据（关键/完成状态/任务模式/任务与里程碑/资源，仅改变显示，不改大纲）；⤓ 向下填充 Ctrl+D（先点列，再多选行）；显示 ▾ → 任务窗体（底部详细信息：名称/工期/开始/完成/完成%/模式/资源/前置/备注 + 前置/后续任务表，▲▼切换任务）。

- 2026-10-11：对标第二轮：⊘ 停用任务（不再驱动后续/摘要）；✓ 按日程标记；移动 ▾（±1天/1周/4周）；📅 日程表；日历视图；显示 ▾ 延迟任务 / 可宽延时间 / 日程表；Ctrl+F 查找、Shift+F2 任务信息、Ctrl+滚轮缩放；🖌 格式刷（单击一次、双击连续、Esc 退出）；完成% 列显示进度条+数字，100% 显示 ✓，分组按工期加权汇总。

- 2026-10-11：顶部 ☀ / 🌙 / 🖥 主题切换：浅色、暗色、跟随系统（偏好保存在本机浏览器）；导出始终白底。

- 2026-10-11：MS Project 基础操作对标：Ctrl/Shift 多选；🔗 链接 / 取消链接（Ctrl+F2）；完成百分比 0/25/50/75/100；Ctrl+C/X/V 复制剪切粘贴行（含子任务、内部链接）；Insert 插入；↑↓ / Shift+↑↓ / F2 / Ctrl+A；拖动 ID 列移动行；显示 ▾ 大纲级别 / 滚动到任务 / 放大缩小。

- 2026-10-11：新增「＋ 新建项目」（默认先下载当前项目备份）；工具栏文本样式（字体/字号/粗体/斜体/颜色，Ctrl+B/I），「显示 ▾ → A 文本样式」设置任务/里程碑/摘要默认，导出跟随。
- 单页应用，不再有「② 客户节点」页，也不再生成推荐任务（r1–r13）
- 工具栏「+ 客户里程碑」：选主机厂 → 勾选节点、填日期（可按标准间隔补全）→ 作为“必须开始于”里程碑插入「客户里程碑 · 主机厂」分组；再次打开可改日期或取消勾选移除
- 插入的里程碑可正常编辑、删除、加前置/后续任务；阶段色带按所选主机厂显示
- 数据独立保存（gantt-exec-v4 / gantt-workcal-v4），不影响 v3.7 的数据
